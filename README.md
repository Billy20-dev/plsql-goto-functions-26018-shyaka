# plsql-goto-functions-26018-shyaka

C2 — Reflection

1. What I learned about GOTO statements

In this assignment, I learned how the PL/SQL GOTO statement can be used to transfer program execution to a labeled section of code. I also learned that GOTO has restrictions and that some jumps are illegal in PL/SQL. I demonstrated an illegal GOTO, observed the Oracle error, and corrected the program.

2. What I learned about functions

I learned how to create stored PL/SQL functions that accept parameters and return values. I created functions for calculating annual salary, determining years of service, calculating tax, and obtaining a department name.

3. Using functions in SQL

I learned that PL/SQL functions can be called directly from SQL statements. In B5, I used functions inside a SELECT statement to display calculated employee information.

4. Exception handling

I learned how exception handling can prevent a program from failing unexpectedly. For example, the functions can handle NO_DATA_FOUND when an employee or department does not exist.

5. Most challenging part

The most challenging part was understanding the restrictions of the GOTO statement and understanding how stored functions work with SQL. Testing the programs and correcting errors helped me understand these concepts better.

6. How I solved the challenges

I solved the challenges by running each program in Oracle SQL Developer, checking the output and error messages, correcting the code, and testing the functions with employee data.

7. What I would improve

I would improve my understanding of PL/SQL by practicing more functions, exception handling, and database programming problems. I would also try to write programs that are clear, simple, and easy to maintain.

8. Conclusion

This assignment improved my understanding of PL/SQL GOTO statements, stored functions, exception handling, and using functions in SQL. It also gave me practical experience organizing SQL projects in GitHub and documenting my work.
